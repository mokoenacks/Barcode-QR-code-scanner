# Barcode and QR code scanner

Windows Forms app that reads QR codes and barcodes from a webcam.

## Stack

- C# on .NET Framework 4.6.1
- AForge.Video for the camera
- ZXing.Net for decoding

## Run it

Open `QR code scanner.sln` in Visual Studio and start the project. Pick a camera, then start the scan. The decoded value shows in the text box.
